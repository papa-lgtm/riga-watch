# Ежедневное отслеживание судов в ремонтных зонах Риги

Сбор данных о судах, которые стоят без движения в рижских ремонтных зонах.
Работает на бесплатном потоке aisstream.io и бесплатных минутах GitHub Actions.

## Что делает

1. Раз в несколько часов подключается к потоку автоматической идентификационной
   системы судов (AIS) на 10 минут и собирает все суда в районе Рижского порта.
2. Отбрасывает буксиры, лоцманские катера, земснаряды и всё короче 55 метров.
3. Отмечает суда, которые стоят со скоростью почти ноль внутри ремонтных зон.
4. Когда судно простояло в зоне 24 часа — записывает строку в `events.csv`.
   Это и есть сигнал «судно в ремонте, можно писать».

## Файлы

| Файл | Назначение |
|---|---|
| `ais_watch.py` | сам сборщик |
| `zones.json` | координаты зон и правила отбора |
| `state.json` | служебное состояние между запусками, руками не трогать |
| `events.csv` | накопительный журнал сработок — рабочий файл |
| `current.md` | кто стоит в зонах прямо сейчас, в читаемом виде |

## Установка (примерно 15 минут)

1. Создайте на GitHub репозиторий. **Публичный** — тогда минуты Actions
   бесплатны без лимита, а данные AIS и так общедоступны. Если нужен приватный,
   оставьте запуск раз в 6 часов, чтобы уложиться в 2000 бесплатных минут.
2. Загрузите в него `ais_watch.py`, `zones.json` и папку `.github/workflows/`.
3. Settings → Secrets and variables → Actions → New repository secret.
   Имя: `AISSTREAM_API_KEY`, значение — ваш ключ aisstream.
4. Settings → Actions → General → Workflow permissions → включите
   «Read and write permissions». Без этого рабочий процесс не сможет сохранить
   результаты обратно в репозиторий.
5. Вкладка Actions → «Riga repair-zone watch» → Run workflow. Первый запуск
   займёт около 11 минут. После него появятся `state.json` и `current.md`.

## Проверка и настройка зон

Первые двое-трое суток смотрите `current.md` и сверяйтесь с картой MarineTraffic
или VesselFinder глазами. Координаты зон в `zones.json` заданы приблизительно по
адресу судоверфи в Вецмилгрависе. Почти наверняка их придётся подвинуть:
прямоугольник должен накрывать доки и ремонтные причалы, но не главный судоходный
ход, иначе будет ловить суда, стоящие в очереди.

Подвинуть просто: откройте нужное место на карте, возьмите широту и долготу
углов и впишите в `lat_min` / `lat_max` / `lon_min` / `lon_max`.

Остальные настройки в разделе `rules`:

- `max_speed_knots` — выше этой скорости судно считается движущимся;
- `dwell_hours_to_alert` — сколько часов простоя даёт сработку;
- `min_length_m` — отсекает мелочь, длина берётся из габаритов в сигнале AIS;
- `excluded_ship_types` — коды типов судов по стандарту ITU-R M.1371;
  50–59 это служебные суда порта, 30–37 рыболовные и специальные.
